# LinkedIn drafts

The LinkedIn routine writes one short post draft here every three days, named by date
(`2026-10-31.md`), based on new entries in `../UPDATES.md` and new activity on
github.com/Yarida-nes. Nothing is posted automatically: open the file, copy the text,
paste it into LinkedIn, and edit it in your own words first.

Each draft has:

- a post of 80 to 150 words with one concrete result and a link to the case study,
- a suggested headline line for the LinkedIn profile if it should change,
- a note on which profile sections (About, Experience, Projects, Skills) to update, with the text to paste.
