Case studies

How the analysis was actually done.

Three university analytics projects, written up with the question, the method, and what the numbers showed.

01

ESG and financial analytics, Asia-Pacific

  • Tableau
  • ACCT5034, Curtin
  • 2026

Do companies that score well on environmental, social and governance measures also perform better financially? I built a Tableau Story of three linked dashboards to test that across nine Asia-Pacific countries.

What I built

  • Three interactive dashboards in a single Tableau Story, moving from country-level comparison down to individual firms
  • Calculated fields, parameters and filters, so a reader can change country, sector or year without leaving the view
  • Dashboard actions linking the views, so selecting a country filters the charts below it
  • Forecasting applied to the financial performance measures

What I analysed

  • ESG score and ESG controversies against financial performance
  • Return on assets, Tobin’s Q and market-to-book ratio
  • Market capitalisation, as a control for company size
  • Governance structure: CEO duality and board diversity

Outcome

I wrote the findings up as a business analyst report with recommendations for firms: what the relationships in the data suggest about governance structure and disclosure, and where the evidence was too thin to support a claim.

02

Credit risk analysis

  • RStudio, R Markdown
  • ECOM5005, Curtin
  • 2025

Given loan and borrower records, can we predict which loans will default? I built and evaluated a logistic regression classifier in RStudio.

Method

  • Cleaned the loan and borrower data and handled missing values
  • Explored relationships between the financial variables visually before modelling
  • Fitted a logistic regression model to predict loan default
  • Documented the analysis in R Markdown, so it reruns end to end

Evaluation

I judged the model on accuracy, the ROC curve and AUC rather than accuracy alone. Default data is imbalanced, so a model can look accurate while missing most of the defaults that actually matter.

03

Australian housing prices

  • RStudio, R Markdown
  • ECOM5001, Curtin
  • 2026

What drives housing price growth across Australian cities, and how much of it can a regression model actually explain? I built four competing models and compared them.

Method

  • Analysed housing price growth across Australian cities in RStudio and R Markdown
  • Built four regression models using macroeconomic, seasonal and COVID-19 variables
  • Compared them on R-squared, adjusted R-squared, RMSE and MAE. Adjusted R-squared matters here, because adding variables inflates plain R-squared
  • Plotted actual against predicted values to see where each model broke down

Outcome

The actual-versus-predicted graphs did the interpretive work. They showed which periods the models tracked well and which they could not explain, which tells a reader more than a single fit statistic.
