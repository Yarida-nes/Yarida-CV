# What I did (update inbox)

Every three days, three cloud routines read this file and your GitHub account
(github.com/Yarida-nes), then open pull requests:

- **Website** updates the project pages, Experience, Education and Skills on yarida-cv.vercel.app.
- **CV** updates the wording in `cv/make_cv.js` (the CV builder).
- **LinkedIn** writes a short post draft into `linkedin/` for you to paste.

Nothing goes live until you press **Merge** on the pull request.

## How to add an entry

Add a line under **New entries** with the date and a sentence or two. Write it
from your phone on github.com (open this file, press the pencil, type, press
"Commit changes"). Be specific: numbers, tool names, what the result was.
The routines never invent facts, so if a detail is missing they leave it out
and ask for it in the pull request.

Once the Website routine has used an entry it moves it under **Done** with the date.
The CV and LinkedIn routines also read entries under **Done** from the last ten days,
so nothing is missed while a pull request is still waiting for you.
